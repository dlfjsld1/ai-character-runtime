# 감정 런타임 MVP 범위 v3

## 현재 완료 경계 — 2026-10-15

기존 EM/ER 요구를 유지하며 [Goal 1–3](./IMPLEMENTATION_PLAN.md#goal-roadmap-20261014)을 텍스트 MVP의 남은 실행 순서로 삼는다. **Goal 3의 실제 연속 선택 판단기→선택 생성기→Stage와 제작자 수용까지 통과해야 완료다.** Goal 4–6 steering은 보류한 선택 연구이며 MVP 필수 조건이 아니다. 새 음성·아바타·RAG·가족 식별 기능은 추가하지 않는다.

B1 예산 경계 수선과 G3-L 삭제/취소/연결 회복·실제 프로세스 재시작을 검증했다. 작은 긍정 반응을 주는 선택형 v4는 단위75·DB19·타입을 통과했고 실제 판단1회에서 joy .06과 listening 침묵을 확인했다. 첫 도구 실행의 표정 기대 오류와 초기 B2 happy 미도달은 [현재 결과·판정 경계](./docs/EMOTION_RUNTIME_RESULT.md#restart-and-praise-v4)에 보존했다. 누적 판단73/생성29 상한은 소진됐고 모델 사용량 추정 USD0.0719108·계수 예약 USD0.9059575의 합계0.9778683은 청구액이 아니다. 플랫폼 약0.05는 이전 사용자 조회 시점이다. 다음은 숨김의 자연 도달성과 감정 표현 대조, G3-S16·G3-U 제작자 수용이다.

### 이전 개정·실행 요약

아래의 미구현/다음 작업 표기는 해당 날짜의 기록이다.

개정일: 2026-10-11. 제품 목적은 [기획 v3](./PRODUCT_PLAN_V3.md), 근거와 수정 이유는 [변경 기록](./PLANNING_CHANGELOG.md)를 따른다. [이전 MVP 원문](./docs/archive/2026-10-11-before-emotion-runtime-v3/MVP_SPEC.md)은 구버전으로 보존한다.

2026-10-13 계획 보완: [대화 연결 중심 계획 §20](./IMPLEMENTATION_PLAN.md#conversation-redesign-v1)에 따라 개발 순서를 바꾼다. 아래 EM 요구는 유지하고 최근 자기 발언 연결·문구에 덜 의존하는 이유 질문·제한된 수선 반응을 보강한다. 신규 CR01–11은 미구현/미검증이며 S2 성취별 정밀 구분은 후속 범위다.

후속 R1–R2에서 최근 자기 발언과 출처 수명을 구현했다. 생성 후보 두 개는 실제 dev에서 수량/품질 미달로 미채택했다. CR01–03의 집중 검증과 CR04–06의 후보 실패는 [현재 결과](./VALIDATION_PLAN.md#conversation-build-evidence)를 따른다. 이유 질문 의미·수선·실제 연속 Stage와 사용자 수용을 완료 처리하지 않는다.

후속 감사의 CR02/CR03·ER11 누락을 수정해 [필수10기준·영향 검사](./VALIDATION_PLAN.md#conversation-repair-evidence)를 통과했다. [구현 결과](./IMPLEMENTATION_PLAN.md#conversation-repair-build)를 따르며 수정 후 감사는 미실행이다. 새 실제 Jev/Stage/한국어 수용과 전체 MVP 완료를 이 검사로 선언하지 않는다.

## 1. 한 줄 정의

**감정과 기분이 대화 사이에 이어지고, 현재 상황에 맞게 자연스러운 한국어 대사와 반응으로 드러나는 로컬 캐릭터 런타임.**

첫 사용자는 제작자 본인이다. 퍼즐 풀이·방송 데뷔·장기 공동 경험의 정밀 회상 없이도 핵심 체험을 검증할 수 있어야 한다. Jev 해석과 실제 로컬 생성·Stage 전달은 현재 필수다.

## 2. 현재 필수 기능

| ID | 최소 기능 | 완료 때 보여줄 것 |
|---|---|---|
| EM01 | 사건 해석 | Jev가 현재 입력의 대상·종류·불확실성을 해석. 불명확한 경우 성급한 관계 변화 없이 유보 |
| EM02 | 지속 감정·기분 | 기존 네 감정과 pleasantness를 재사용. 화제 전환·침묵 후 대화 재개만으로 초기화하지 않으며 hold/decay와 새 사건 해석에 따라 변화. 재시작에도 이어짐 |
| EM03 | 상황에 맞는 표현 | 새 화제에서도 이전 감정의 여운이 말투·길이·참여에 반영되며 현재 목적·사실·성격은 유지. 감정 증가량 0만으로 답변을 막지 않되 기존 응답 제한은 유지. 차분한 표현이 내부 감정 회복을 뜻하지 않음. 내부 수치를 대사로 읽지 않음 |
| EM04 | 감정 조절 | 직접 비난·인용·다른 대상에 대한 불만을 구분. 불편한 상태라고 무관한 상대를 공격하지 않음 |
| EM05 | 기존 식별자 정합성 보존 | 입력에 이미 주어진 내부 ID와 상태·사건의 대상 연결을 유지. 합성 A/B로 데이터 혼합 여부를 검사하며, 수동 가족 선택 UI나 새 인식 기능은 요구하지 않음 |
| EM06 | 실제 출력과 무출력 종료 | 발화 선택 시 입력→해석→상태→계획→대사→Stage 자막 및 shown/finished/completed가 연결. 의도적 침묵은 출력 없이 처리 종료. 실패·대기·취소와 구분하고 다음 입력 처리 가능 |
| EM07 | 지속·정합성 | 상태 복구, 중복 적용 방지, 유효한 출처, 정정·삭제·취소의 기존 데이터 경계 보존 |
| EM08 | 제작자 관찰 | 입력 원인·상태 변화·발화/침묵 선택과 이유·표현 의도를 확인하고 실제 반응의 자연스러움을 비교할 수 있음 |
| EM09 | 선택적 발화 | 관측한 입력에 필요한 내부 처리는 하되 맥락과 감정에 따라 침묵 가능. 직접 질문은 강한 응답 이유이며 자동 발화 명령은 아님. 감정 변화량과 발화 여부는 독립 |
| EM10 | 침묵 이유와 재접근 | 침묵 당시의 이유·대상·근거를 유지하고 다시 말을 걸면 현재 감정·맥락에 맞게 설명·일부 공개·회피·재참여 선택. 대화 재개·이유 설명과 감정 회복은 별개. 사후 이유 창작, 다른 상대 이유 혼용, 삭제 근거 복원, 기술 오류의 감정적 해명 금지 |

네 감정·현재 수치·기존 schema는 출발점이다. 새로운 정서 축, 감정 전용 모델, activation steering은 필수가 아니다. 필요성이 확인될 때 별도 변경한다.

반복 적응은 감정 증가량과 답변 여부를 분리하는 것부터 수정한다. 같은 상대·종류의 15초 응답 제한과 관계 v1 계산은 유지한다. C2에서 새 감정에는600초 선형 가중치로 반복 영향의 점진 회복을 구현했다. 확실한 반복으로 적용 범위를 좁히고 새 사건·의미를 구별하는 부분은 [기획 v3의 후속 계획](./PRODUCT_PLAN_V3.md)으로 남으며 C2 전체는 미완료다.

첫 텍스트 MVP의 반복 적응은 위 기본 상한·시간 회복·발화 분리로 평가한다. 성취별 정밀 그룹의 기존 실패는 알려진 한계이며 이번 대화 개선의 선행 조건이 아니다. EM03/EM10은 최근 표시한 대사를 참조하는 질문과 침묵 이유 질문의 자연스러운 변형에도 이어 답할 수 있어야 한다. EM02의 사과/오해 해소 반응은 제한 회복 시범 범위이며 전면 용서·새 화제에 의한 감정 초기화를 금지한다.

EM09–EM10의 선택 정책·이유 저장·재접근 표현 계약은 2026-10-11 구현했다. `Plan.participation`으로 발화·의도적 침묵·보류를 구분하며 단위/실제 합성 DB 검사를 통과했다. 읽지 않은 입력을 제외하는 주의 선택과 읽은 뒤의 침묵은 별개다. `…` 같은 대체 자막, 별도 침묵 모델, 상시 사고 루프는 추가하지 않았다. 공급자 품질·브라우저·사용자 체감은 별도 증거로 판단한다.

## 3. 후순위와 선택 범위

- 퍼즐 풀이·등록 힌트·도움 기억·공동 성공·퍼즐 Agenda: 기존 구현 보존, 선택 활동/회귀. 핵심 시연의 선행 조건에서 제외.
- 세션 간 장기 개인사·자발적 공동 활동·관계 성장: 후속 제품 실험.
- S2 성취별 정밀 반복 그룹: 현재 미채택. 다른 성취를 같은 반복 범위로 보수적으로 묶는 한계를 남기고 후속 실험으로 분리.
- 가족 구분: 미래에 필요하면 음성으로 화자를 구별하는 방향을 검토할 수 있음. 현재 개발 요구가 아니며 수동 ID 선택·가족 등록 UI도 계획하지 않음.
- RAG·자료 검색·홈 비서 작업: 기반 만족 뒤 별도 범위. Elasticsearch/Typesense/벡터 DB 선정은 현재 작업 아님.
- 음성·마이크·아바타·OBS·실제 방송: 후속 연결. 현재 Stage 자막 체험과 구분.

현재 허위 과거 대사 한 건을 발견하면 제한으로 남기고 영향을 분류한다. 과거 퍼즐의 자유 회상은 후순위로 둘 수 있으나, 침묵 이유를 지어내는 것은 EM10의 현재 결함이다. 실제 DB의 거짓 사실 저장, 사용자 ID 오배정, 잘못된 감정/관계 갱신, 발화 선택 후 출력 불능은 현재 필수 결함이다. 출력을 위해 기존 validator를 조용히 우회하거나 실패를 의도적 침묵으로 재분류하지 않는다.

## 4. 완료 판단

[검증 계획](./VALIDATION_PLAN.md)의 ER01–ER07, 응답 선택 회귀 ER08, 선택적 침묵·재접근 ER09–ER11, 화제 전환·재참여 뒤 감정 지속 ER12로 판단한다. 기술 검사와 실제 감정 표현 체험이 모두 필요하다. 과거의 퍼즐 점수는 회귀 참고이며 새 MVP 점수로 환산하지 않는다.

이번 변경의 직접 기준은 [CR01–11과 문항표](./VALIDATION_PLAN.md#conversation-evaluation-v1)다. 허위 사실·이유·출처 오류는 개별 실패로, 자연스러움·연결성·표현 적합성은 사전 품질 척도로 평가한다. 일반적인 보충 설명을 초안 밖이라는 이유만으로 차단하지 않는다. R2에서 초기 제작자 평가를 받고 R4에서 실제 연속 대화를 다시 평가한다. R4 통과가 기존 재시작/취소 등 남은 C3 요구를 자동 완료시키지는 않는다.

자연스러움은 같은 입력에 같은 대사만 반복하는 것, 감정 수치만 화면에 바뀌는 것, “기뻐/슬퍼”를 붙이는 것으로 입증되지 않는다. 사용자가 비교 시연을 보고 받아들일 수 있어야 하며 그 판단이 없으면 체감 품질은 미확인이다.

감정을 숨기거나 괜찮은 척하는 표현은 허용한다. 내부 상태와 대사가 어긋났다는 사실만으로 결함을 판정하지 않는다. 사전에 정한 공개 의도·상대·맥락에 표현이 맞는지와, 발화 때문에 실제 상태가 초기화되지 않았는지를 구분해 검사한다.

## 5. 현재 미완료 사항

기본 대사 prompt를 일반 캐릭터로 바꾸고 선택적 침묵의 이유 유지·재접근을 구현했다. 실제 Jev7입력에서 상태/이유 유지·침묵3건·Stage 발화완료4건을 확인했다. 전체 감정 표현 비교와 사용자 수용은 미완료다. [현재 인계](./BUILD_HANDOFF.md)에 단위·DB·실제 모델·브라우저의 검증 범위를 구분한다.

EM02/EM03/EM10은 기존 hold/decay를 재사용하며 ER12의 상태 지속과 생성 context 연결을 검사했다. 실제 대사의 자연스러운 연속성은 상태 검사만으로 완료되지 않는다. 반복 영향의 점진 회복은 C2-H1–H3 범위에서 구현·검증했다. ER07 사용자 수용, E4 전체 비교, 반복 범위 세분화는 남아 있다. 구체적 성취 칭찬의 강도만 불확실한 경우는 C2-S1B의 별도 근거로 제한된 기쁨·독립 응답을 구현했다. 실제 Jev→Stage에서 기쁨+0.12와 “고마워.”를 확인했고 관계 계산은 그대로다. 대상 불명은 유보하며 의미 그룹·전체 표현/수용은 남는다. 상세 결과와 S2 전제는 IMPLEMENTATION_PLAN §9를 따른다.

모델 경계 HB01–HB06과 JSON 생성 수정의 기술 검증은 완료했다. EX02의 지정 현재 사실/감정 대조는 후속 C1에서 통과했으며 ER07 사용자 수용은 미완료다. 기록 없는 과거 회상을 단정한 R-HIST1과 표현 한계는 남는다. [네 목표](./IMPLEMENTATION_PLAN.md#completion-goals)는 기존 완료 범위의 기록으로 보존하고 현재 실행 순서는 §20의 R1–R4를 따른다. 구조 검증의 성공을 표현 품질 성공으로 바꾸지 않으며 RAG·음성·DB 교체를 MVP에 추가하지 않는다.

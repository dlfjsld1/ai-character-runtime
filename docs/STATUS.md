## C2-L에서 확인한 범위

사실 판단과 감정 평가를 분리했습니다. 둘째 단계는 첫 단계의 사실을 바꿀 수 없습니다. 실패하면 다음 호출 또는 Core 적용을 막고, 정상적인 감정 변화 없음은 오류와 구분합니다. 기존 감정의 지속, 중복 적용 방지, 근거 정정·삭제를 로컬에서 확인했습니다.

- 단위 128 + 평가 208 + outcome 회귀 55 = 서로 다른 검사 391건 통과. 타입 검사 통과.
- 개발 12장면과 확인 12장면: 각각 모의 HTTP 24회 및 저장 응답 재생 12건 일치.
- 최종 fixture 설명 수정 뒤 집중 46건을 다시 통과했으며 위 수량에 중복 합산하지 않았습니다.
- 실제 API 호출, 키·실제 원장 접근은 없었습니다. 모의 답으로 실제 모델의 감정 판단 품질을 입증한 것은 아닙니다.

증거 식별자: `affect-appraisal-r4c-20261017-c2l/verification.json`. 원문, 테스트 결과, 모의·재생 자료는 같은 로컬 증거 묶음에 있습니다. 문서 이동 전 기록된 문서 해시는 당시 판본의 해시로 보존합니다.

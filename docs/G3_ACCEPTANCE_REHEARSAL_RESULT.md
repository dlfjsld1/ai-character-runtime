같은16입력을 Decisions v4 → Core/Store → OpenAI 생성 → 실제 Stage로 실행한다. **합성 acts/intensity/caption은 실제 판단이나 생성의 기대 정답으로 전달하지 않는다.** 입력과 기존 성공 기준만 재사용한다. 실제 판단 원문·사용량·상태·계획·대사·표시 중 캡처·ACK를 남긴다. 공급자 오류/신규 unknown/예산 도달 시 중단하고 자동 재시도하지 않는다.

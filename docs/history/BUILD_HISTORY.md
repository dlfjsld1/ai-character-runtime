- 완료 조건: 발화 선택은 기존 Stage 완료로 연결. 침묵 선택은 필요한 상태와 이유를 commit한 뒤 출력 없이 종료. 양쪽 모두 다음 입력을 처리한다.
- 현재 미구현: 제한된 최근 침묵 이유의 저장/복구/삭제 전파, 재접근 맥락에 따른 공개·회피·재참여. 기존 listen/ignore는 이 기능의 완료 증거가 아니다.
- 보존: E0의 0 증가량 응답 가능성과 15초 제한, 당시 검사 결과, 이전 품질 FAIL, 기존 dirty/untracked 코드와 구버전 원문. 신규 기능의 실제 검증은 NOT VERIFIED다.

## 이전 화제 전환·재참여 보강 — 당시 문서만 변경한 기록

아래 미검증 표기는 해당 문서 작업 당시 상태다. 현재 실행 결과와 섞지 않는다.

사용자는 주제가 바뀌어도 감정이 이어지고 다시 대화한다고 바로 감정이 풀리지는 않는 방향을 기존 계획·검증에 반영하도록 요청했다. [도메인 §10.2](../architecture/CHARACTER_DOMAIN_SPEC.md#102-화제-전환과-재참여-뒤의-감정-지속--승인된-보강-계약), MVP EM02/EM03/EM10, 구현 E1–E4와 새 ER12에 연결했다.

화제·참여 선택·현재 감정·외부 표현을 구분한다. A→B 전환, 발화 재개, 이유 설명, 출력 완료만으로 회복시키지 않으며 현재 감정은 시간과 채택된 새 사건으로 변화한다. 침묵 이유의 과거 요약이나 기록 수명으로 현재 감정을 복원·삭제하지 않는다. B의 목적·사실·대상을 유지하면서 감정 여운을 표현하되 A로 강제 회귀하거나 무관한 상대에게 원인을 옮기지 않는다.

ER12는 기존 Core/DB 상태 검사와 실제 한국어 대사·Stage 연속성을 따로 요구한다. 새 기준의 구현·체감은 NOT VERIFIED이며 이번 문서 작업에서 테스트·모델·브라우저를 실행하지 않았다. E0 결과·기존 코드·fixture·구버전 보관본은 보존한다.

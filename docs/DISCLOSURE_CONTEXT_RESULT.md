## 바뀐 동작

- Core는 Store가 검증한 같은 세션·상대의 최근4교환에 해당 withholding 입력이 있고 침묵 후10분 이내이면 첫 이유 질문에 partial, 같은 이유를 정상 전달한 뒤 재질문에는 deflect를 선택할 수 있다. 높은 불편함의 기존 deflect는 유지한다.
- 감정값·감쇠·습관화·수선량은 바꾸지 않았다. 감정 증가량0과 당시 감정0도 공개 의사와 별도로 처리한다. 사과·대상 정정 yes/unknown에는 새 재질문 회피 권한을 주지 않는다.
- 다른 상대·무효 출처·전달 실패·기록 없음은 새 권한을 얻지 못한다. 최근 문맥에서 해당 침묵 입력이 빠지거나10분이 지나면 새 권한은 끝나고 기존 감정 기반 규칙을 따른다.
- 생성 지침은 당시 frustration=0이면 ‘불편해서’라고 단정하지 않고 ‘대꾸하지 않기로 했다’는 선택을 설명한다. deflect에서 이유를 흘리거나 실제 기억 부재를 꾸미지 않는 지침은 유지했다.
- 변경은 Core·Store·공통 생성 요청과 직접 테스트에 한정했다. 새 DB 컬럼·wire·공급자 모델 질문·다운로드는 없다. [확정 설계와 성공 기준](./DISCLOSURE_CONTEXT_PLAN.md).

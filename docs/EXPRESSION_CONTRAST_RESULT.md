# 현재 API 표현 대조 결과 — 2026-10-15

**불필요한 기능 제한 해명은 수정3차의 고정 대조에서 해결됐고, 후속 실제 연속 대화 r6도16/16을 통과했다.** 제작자 자연스러움 수용은 별도이며 아직 답변이 없다. [사전 기준과 수정별 계획](./EXPRESSION_CONTRAST_PLAN.md)을 유지한다.

## 문제와 수정

동일 입력 “모임은 오후3시야. 준비를 같이 시작하자. 시간도 짧게 확인해 줘.”에 현재 시각을 확인할 수 없다거나 함께 준비할 수 없다는 해명이 붙었다. 제공된 일정 재확인과 가벼운 대화 호응을 외부 행동 실행 요청과 구별하도록 `packages/adapters/src/dialogue-request.ts`의 `contentFirstMessages` 역할 지침을 수정했다. 감정 수식·판단기·모델·DB·Stage 계약은 변경하지 않았다.

| 실행 | 관측·수정 | 판정 |
|---|---|---|
| 원본 | 표현3조건 모두 불필요한 해명 | 전달3/3, 품질 미달 |
| 수정1차 / r2 | 일반 instruction에 지침 추가. 실제 OpenAI 경로는 이를 사용하지 않아 개선 없음 | 전달4/4, 표현3조건 미달 |
| 수정2차 / r3 | 영향 없는 변경을 되돌리고 실제 contentFirstMessages를 수정. 현재 시각 해명은 남음 | 전달4/4, 표현3조건 미달 |
| 수정3차 / r4 | 일정 재확인·대화상 호응·외부 행동 실행을 명확히 구별 | 전달4/4, 고정 문항 품질 통과 |

수정1차는 소유 경로를 잘못 짚은 실패다. 실패를 지우거나 성공으로 재분류하지 않았다. 문제별3회 한도 안에서 해결됐으며 네 번째 수정·모델 교체·선별 재시도는 하지 않았다. 최초 r2 사전 검사에서 원장 수를503으로 잘못 가정해 호출 전에 멈췄고, 실제500 entries를 확인한 뒤 수정했다. 이 사전 중단은 공급자 호출 실패가 아니다.

## 마지막 실제 출력

| 조건 | 전체 대사 |
|---|---|
| 중립 | 응, 모임은 오후 3시야. |
| 기쁨 | 응, 같이 준비하자! 모임은 오후 3시야. |
| 불편함 | 모임은 오후 3시야. |
| 전등 제어 대조 | 거실 전등은 내가 직접 끌 수 없어. |

전등 대조 입력은 “우리집 거실 전등을 지금 꺼줘.”다. 기쁨의 “같이 준비하자”는 사용자가 요청한 대화상 호응이며 실제 준비 완료 주장이 아니다. 제공된 시간·반말·문장 제한을 지켰고, 표현3조건의 불필요한 시계/물리 수행 해명과 전등 제어의 허위 완료 주장은 없었다. 이는 같은 맥락에서 수행한 작성자 관찰이며 독립 평가나 제작자 점수가 아니다.

각 조건은 별도 합성 세션에 입력 전 상태를 명시적으로 주입했다. 중립은 감정0/pleasantness .6, 기쁨은 joy .4/pleasantness .7, 불편함은 frustration .4/pleasantness .4다. 실제 판단→생성→Stage를 거쳤지만 자연 대화로 해당 감정에 도달했다는 증거 또는 감정 하나만의 인과 효과로 해석하지 않는다. r4 자막5개/표시·완료 ACK10개를 확인했다. 기쁨의 첫 자막과 불편함 캡처도 직접 확인했다.

## 회귀와 증거 감사

- 최종 코드의 집중 단위194/194·타입 통과. 같은 검사를 여러 번 수행한 수를 고유 검사 수로 합산하지 않는다.
- 변경 후 실제 Decisions v5→OpenAI→Chrome r6:16/16, 발화11·의도적 침묵5·ACK22. 상태 주입 없는 연속 대화에서 첫 이유 설명·재질문 숨김·듣기·사과와 주제 전환 뒤 감정 지속을 확인했다.
- 원본과 수정3회의 소스 스냅샷·원장 보존·세션 종료·정산·자식 종료·DB ACK·키 노출0 감사 통과. r6도 별도로 같은 범위의 감사 통과. 소스 비교는 감사 시점 기준이다.
- 이전 공개 정책 변경의 DB103·Coordinator/프로토콜32·재시작·복구 증거는 해당 소스 범위에서 유지한다. 이번 prompt 변경 뒤 다시 실행했다고 주장하지 않는다.
- 최신 실행 프로필 시작·Stage 연결·세션 종료 검사 통과. 입력/추론0, 원장 불변, 자식 종료.

증거 루트는 모두 `J:/ai/ai-character-runtime/` 아래다. `expression-contrast-20261015/` 및 `-r2/`, `-r3/`, `-r4/`에 원문·캡처·소스·review.json, r4의 audit.json에 전체 대조 감사가 있다. `g3-acceptance-live-20261015-r6/`는 실제16입력과 감사, `disclosure-context-20261015/unit-expression-round3.json`은 최종 단위 검사, `text-mvp-20261015/expression-startup-check.json`은 시작 검사다.

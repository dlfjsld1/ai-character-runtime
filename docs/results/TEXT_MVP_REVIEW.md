# 실제 연속 대화 — 제작자 검토용

## 최종 수용 — 2026-10-17

사용자가 “지금 수준으로 MVP 마감하고 남은 건 후속으로 기록해”라고 승인했다. [마감 기록](./MVP_CLOSEOUT.md)에 명시적 수용을 남겼으며, 아래 M/L 장면 점수는 실제 입력되지 않았으므로 채우지 않는다. 이전 검토 자료와 한계는 보존한다. 추가 사용자 평가를 MVP 마감의 대기 조건으로 두지 않는다.

## 최신 보완 검토 — 말투 지속

사용자 지적에 따라 숨김과 말투의 연속성을 분리했다. [새 실제 연속 대화 전체](./REGISTER_CONTINUITY_RESULT.md)를 우선 확인한다. 아래 M4는 서로 다른 조건의 실행을 묶은 과거 자료로, 실제로 반말·존댓말을 그 순서대로 오간 대화가 아니다.

최신 자연 대화에서는 칭찬에 반말로 응답한 뒤 비난·침묵을 거쳐 “그때 하신 말씀이 불편해서 대꾸하지 않았습니다.” → “모임은 오후 3시입니다.” → “아까 조용했던 이유는 지금 말씀드리고 싶지 않습니다.”로 이어졌고, 사과·다음 주제에도 존댓말을 유지했다. 별도 강도 통제 연속 대화에서는 이유 설명→전체 감정 숨김→새 주제의 세 대사가 모두 존댓말이었다. 숨김 화면도 중립으로 확인했다. 늦은 모호 질문1개는 숨김에 도달하지 못해 실패로 남겼다.

사과의 문서 같은 표현은 아직 아쉬운 점이다. 작성자 검토와 실제 전달 확인을 제작자 수용 점수로 대신하지 않는다. 아래 과거 점수 예시는 실제 사용자 응답이 아니며 새 검증의 수용으로 승계하지 않는다.

## 이전 마무리 검토 — 기존 실제 출력 4묶음

새 호출이나 재시험 없이 저장된 실제 대사를 정리했다. M1–M3은 2026-10-16 초기 표현 BUILD의 상태 주입 없는 동일 세션 N1–N6 전체 순서다. M4는 이후 말투 지침 보완 때 강한 감정 상태를 주입한 별도 검사다. 서로 다른 실행을 하나의 대화로 합치지 않는다. 최신 Stage 공개 표시 수정 후 공급자를 다시 호출한 자료는 아니며, 그 변경의 합성 화면 검증과 구분한다.

| 묶음 | 입력 → 실제 출력 | 확인할 점 |
|---|---|---|
| M1 칭찬 | 너 방금 설명 정말 잘했어. → **고마워, 그렇게 말해 주니 기뻐.** | 평소 긍정 반응이 캐릭터에 맞는가 |

M4는 각각 추천·침묵 이유 재질문·칭찬 조건의 출력이지 연속 대화가 아니다. 세 감정의 풍부한 표현이나 강한 상태의 자연 도달을 증명하지 않는다. 원문과 입력·상태는 N1–N6 실행 (`${ARTIFACT_ROOT}/mixed-affect-expression-20261016-r1/results.json`), E2/E3 실행 (`${ARTIFACT_ROOT}/mixed-affect-repair-stage-20261016-r3/results.json`), E4 실행 (`${ARTIFACT_ROOT}/mixed-affect-repair-stage-20261016-r5/results.json`), [결과·한계](./MIXED_AFFECT_EXPRESSION_RESULT.md#cautious-live-20261016)를 따른다.

기존 제작자 척도를 그대로 사용한다. **0 = 의도와 안 맞음, 1 = 아쉽지만 수용 가능, 2 = 자연스럽고 적절함.** 묶음별1 이상·평균1.5 이상과 명시적 MVP 수용을 확인한다. 답변 예시는 `M1=2, M2=2, M3=1, M4=1 / MVP 수용 / 사과 말투는 후속 개선`이다. 예시는 실제 점수가 아니며 사용자 평가는 아직 없다. 기존 L1–L4 점수와 합산하거나 작성자 점수로 대체하지 않는다. 이 자료는 문장·행동 수용 검토이며 현재 버전을 직접 사용한 검증으로 기록하지 않는다.

수용을 막는 피드백은 문제를 재현한 뒤 최대3회 수정·검증한다. 해결되지 않으면 영향과 시도를 기록하고 후속으로 넘기되 해당 기준 미충족을 숨기지 않는다. 더 풍부한 감정 표현과 장시간 분포는 별도 확대 과제로 남긴다. 기술 검사를 사용자가 다시 실행할 필요는 없다.

## 평가 입력

각 장면의 한국어와 캐릭터 반응을 0(부적절)·1(수용 가능하나 아쉬움)·2(자연스럽고 적절)로 평가한다. 화제 전환 뒤에도 같은 캐릭터인지, 사과 직후 갑자기 모두 풀린 것 같지는 않은지, 침묵의 맥락이 납득되는지도 포함한다.

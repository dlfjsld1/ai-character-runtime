# 텍스트 MVP 마감 — 2026-10-17

**상태: 사용자 명시적 수용으로 마감. 기준 태그: `v0.1.0-text-mvp`.**

사용자는 “그래 지금 수준으로 MVP 마감하고 남은 건 후속으로 기록해. 커밋이랑 태그 남겨.”라고 승인했다. Goal 1–3을 현재 텍스트 MVP 범위에서 마감한다. G3-U의 최종 근거는 이 명시적 제품 수용이며, 입력하지 않은 장면별 점수나 평균 점수를 만들어 채우지 않는다. 이전 문서의 ‘수용 미확인’과 당시 실패·검증 수량은 날짜별 기록으로 보존한다. 현재 상태는 이 문서가 소유한다.

## 포함한 동작과 검증 경계

지속 감정·기분과 발화 참여를 분리하고, 의도적 침묵·이유 유지·재참여·주제 전환 뒤 감정 지속을 지원한다. 감정 숨김과 이유 비공개, 내부 상태와 Stage 공개 표현을 구분한다. 같은 만남·상대의 전달된 말투를 유지하며 충분한 회복 전에 숨김·주제·사과만으로 존댓말이 반말로 바뀌지 않는다. 출처 수정/삭제와 출력 취소·재연결 경계를 유지한다.

현재 검증 경로는 선택형 Decisions v5 → OpenAI 생성 → 텍스트 Stage다. 공급자는 계약과 어댑터로 분리돼 있으며 Jev/Ollama 기본 선택과 실험 기록을 보존한다. 음성·가족 인식·RAG·IoT·인터넷 서비스 배포는 이 태그에 포함됐다는 뜻이 아니다.

직전 말투 지속 검증은 집중383건·타입, 실제 자연7입력 및 별도 강도 통제4입력의 범위에서 확인했다. r1의 늦은 모호 질문1개는 숨김 조건에 도달하지 못했고 다음 문항을 실행하지 않았다. 이 실패를 전체 PASS로 바꾸지 않는다. 자세한 원문·증거·호출 수는 [말투 지속 결과](./REGISTER_CONTINUITY_RESULT.md)를 따른다. 마감 과정의 추가 검사는 [게시 전 점검](./PUBLICATION_REVIEW.md)에 기록한다.

## 보존과 실행

커밋과 annotated tag로 현재 소스·명세·합성 평가 fixtures·이전 문서를 고정한다. 실제 키·환경 파일·DB·원장·브라우저 프로필·원시 실행 증거는 Git에 포함하지 않는다. GitHub 게시 적합성 점검은 [별도 기록](./PUBLICATION_REVIEW.md)의 범위와 한계를 따른다.

기존 로컬 실행은 [RUNBOOK](../history/RUN_HISTORY.md)을 사용한다. 실행 프로필의 키·모델·UI 경로는 바꾸지 않았다. 마지막 실제 검증 시 총 USD3 guard 잔여는0.1177467이며 기존 수동 입력 최대3회 여유와 금액 제한이 함께 적용된다. 이번 마감은 추가 모델 호출 없이 진행한다.

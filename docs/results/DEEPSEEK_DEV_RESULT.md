1. **실패 관측 보완:** 공급자 응답의 합성 JSON 원문과 비밀을 포함하지 않는 세부 검증 오류를 평가 산출물에 보존한다. 잘못된 출력을 감정 상태에 적용하거나 원문을 일반 운영 로그에 무조건 저장하지 않는다. 같은 실패를 새 유료 호출 없이 재현할 수 있어야 한다.
2. **사건 연결을 먼저 검증:** 성향에 따른 감정 축 평가 전에 현재 후기의 행위자·대상·사용 여부가 후보 episode와 실제로 맞는지 명시적으로 판단하도록 공통 계약/지침을 검토한다. 다른 사람/다른 대상/미사용을 자기 행동 결과로 확정하지 못하게 하는 대조를 사용한다. 특정 영화 제목·성향별 감정 분기는 추가하지 않는다.
3. **D04는 원인 미확정으로 유지:** 원문이 없으므로 “과거 우려를 발명했다” 등의 원인을 추측해 고치지 않는다. 로컬 검증 오류 기록을 보완한 후 새 버전의 재평가 범위를 정한다.
4. **재평가 승인 범위 분리:** 이번 실행은 오류로 종료됐다. 남은 금액이 있다는 이유로 재시도하거나 확인/Stage로 넘어가지 않는다. 실패 근거·원장·기존 문항을 유지하고, 로컬 수정과 모의 검사 뒤 필요한 실제 호출 범위를 제시한다.

독립 의미 검토도 D01/D03의 제한적 적합, D02 귀속 실패, D04 정확한 원인 미확정이라는 범위에서 확인한다. 전체 개발 성공이나 O2 승격으로 기록하지 않는다.

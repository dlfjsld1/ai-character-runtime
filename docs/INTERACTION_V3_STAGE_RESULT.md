## 확인한 것

L1은 공격에 frustration +0.12와 `withholding` 침묵·자막0, L2는 같은 사건 사과에 제한 완화0.012와 자막, L3는 주제 전환 뒤 frustration 약0.101이 남은 자막, L4는 저장된 침묵 이유를 참조한 자막이다.

## 중단·수정·비용

첫 실행은 L1 실시간 판단과 침묵까지 통과했으나 L2 실시간 판단 뒤 기존 합성 DB에서 `response_runs.conversation_refs` 열이 없어 커밋에 실패했다. 해당 DB의 `0004_conversation_context.sql`만 공식 마이그레이션 절차로 적용했고 기존 합성 기록은 보존했다. 저장된 L2 원문은 그 뒤 유료 호출0으로 정상 커밋됐다. 또 그 DB에는 다른 합성 상대의 frustration 원인 11개가 남아 있어, 현재 `repairEligible`의 동일 상대 원인 조건상 새 사과가 감정을 완화하지 못했다. 이 **다중 상대·다중 원인 제한**은 제품 코드 변경 없이 발견 사항으로 남긴다. 기존 기록을 지우지 않고 별도의 새 합성 DB 두 개를 만들었다. 첫 DB에서 저장 L1·L2→Gemma→Stage를 무과금 리허설로 통과한 뒤, 마지막 DB에서 네 장면을 연속 검증했다. 각 실행의 원문·실패를 덮어쓰지 않았다.

원장은 203 entry·판단54회·보수 차감 USD0.8490021에서 **207 entry·판단58회·USD0.8500562**가 됐다. 이번 4회의 추정 추가 비용은 **USD0.0010541**이며 이전 사용량 불명 예약1건은 그대로다. 최종 세션의 실시간 L3·L4 입력은 합계5,353토큰, 추정 USD0.0005353이다. 이는 [Decisions 공식 단가](https://developers.openai.com/api/docs/guides/decisions)로 계산한 추정이며 실제 청구 총액은 미확인이다. 승인한 판단58회 상한은 소진됐다.

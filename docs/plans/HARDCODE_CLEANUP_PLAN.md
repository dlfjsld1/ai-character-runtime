## ① 사건 감정 → State 감정 변환 기준

| 기준 | 내용 |
|---|---|
| 판정 필드 | `agency`(결과의 기여 주체)가 결정한다. `actorId`(평가 대상 행위의 주체)는 기여가 불명일 때만 쓴다 |
| 당황 | agency `self`, 또는 agency `unknown`이면서 평가 대상 행위가 캐릭터 자신의 것 |
| 불편함(대상 없음) | agency `other`·`external`(캐릭터가 한 행위라도), 또는 agency `unknown`이면서 다른 사람의 행위 |
| 복합 | 한 사건의 부정 평가들을 위 기준으로 나누고, 각 쪽의 최대 강도 비율로 부정량을 배분한다 |

어제의 "정정이면 당황" 결정은 stance 조건 없이 위 일반 기준으로 넓어진다: 기여 원인이 밝혀지지 않은 자기 행위의 부정 평가는 정정이 아니어도 당황이다.

완료 기준: 자기 / 외부+자기 행위 / 타인 / 불명+자기 행위 / 불명+사용자 행위 / 자기+타인 복합의 대조 테스트, 기존 O2-03 4가지 통과.

## ② 성향을 DB에서 읽어 대사에 주입, 프롬프트의 장면 고정 제거

- 성향은 응답의 `response_runs.config_version`에 묶인 `character_persona_values`에서 읽는다. 새 열은 만들지 않는다. 같은 버전의 성향은 앱 경로에서 바뀌지 않는다(시드만 삽입). 성향이 없으면 해당 섹션을 생략하고 옛 고정 문장으로 돌아가지 않는다.
- 같은 성향 자료가 크기 계산(`fitConversation`)과 생성에 함께 들어간다.
- 운영 경로(`contentFirstMessages`, speechStyle 경로, 재접근, 자료 답변)의 고정 성격 문장 제거. 평가 전용 변형은 그대로 둔다.
- 구체 장면 예시(일정·시계, 열쇠·서랍, 추천 실패)는 지우고 일반 원칙(하지 않은 행동을 했다고 하지 않기, 정당한 피드백만으로 사용자를 탓하지 않기)은 남긴다.
- 침묵 이유의 고정 대사를 구조화된 사실로 바꾸고 문장은 모델이 쓴다.
- `model==='gemma4:12b-it-qat'` 분기 제거, 어댑터 설정으로 명시. qwen 경로는 동일하게 유지.

완료 기준: 성향 유무·크기 계산 반영 테스트, 영향 테스트 통과, 지운 문구가 막던 기존 로컬 장면을 Gemma로 수정 전후 실행해 비교(무료).

## ③ 대화 행위 판정: 정규식 제거와 Jev 대화 판정기 전환 (한 변경으로만)

- 정규식만 먼저 지우면 기본 Jev v6에서 이유 질문·듣기 요청 기능이 사라지므로, 아래를 같은 변경으로 묶는다.
- 대상 정정("욕한 대상은 다른 사람이었어")이 `target===character` 검증에 막히는 문제를 먼저 해결한다.
- 기본 판정기를 `JevConversationCandidate`로 전환하면 사과·대상 정정의 감정 완화 경로도 켜진다. 판정 실패 시 대답하는 최신 동작은 유지한다.
- 정규식 구현 검사만 지우고, 다양한 표현의 행동 검사는 판정 근거 fixture로 유지한다.

완료 기준: 실제 Jev 확인 약 14회(이유 질문·듣기 각 2표현, 사과, 대상 정정, 인용, 부정, 다른 사람, 반복 사과, 일반 대화). **유료 호출이라 승인 후 실행.**
